How it works

  1. Drop an image in any supported format.
  2. Choose the output format in the Export dialog and set the quality if needed.
  3. Click Download to save the converted file.

Which format to convert to

JPEG is the universal choice for photos: small files that open on every device, but no transparency. PNG is lossless and keeps transparency, which makes it ideal for screenshots, logos, diagrams and anything with sharp edges or text; photos saved as PNG are large. WebP supports both quality-based compression and transparency and usually gives the smallest files, though some older software can’t open it. A layered PSD is the right choice when someone will keep editing the file in Photoshop or another editor that reads PSD.

Formats you can open

Paint Studio reads PNG, JPEG, WebP, BMP and SVG, the first frame of a GIF, AVIF if your browser can decode it, iPhone HEIC/HEIF photos and 8-bit Photoshop PSD files with their layers. Drag the file onto the page, use the file picker, or paste an image copied from another app with Ctrl/⌘+V. SVG drawings are turned into pixels when they open, so the result is a regular bitmap; there is no SVG export or vector editing. Animated GIFs come in as a single still image.

What changes during conversion

Converting re-encodes the pixels rather than just renaming the file. Transparent areas become white when you save as JPEG, so pick PNG or WebP for logos and cut-outs. JPEG and WebP use the quality slider (10–100): around 85–92 keeps photos visually unchanged, lower values save space. Converting a JPEG to PNG won’t restore detail that JPEG compression already removed — it only prevents further loss. Each file is converted on its own; there is no batch conversion of whole folders.

Frequently asked questions

Can I convert images to AVIF or HEIC?

No. Paint Studio can open AVIF and HEIC files, but saves only PNG, JPEG, WebP, layered PSD and its own .paint project format. If you want a modern, compact format with wide support, WebP is a good alternative.

Does converting to JPG lose transparency?

Yes. JPEG has no transparency, so transparent pixels are filled with white during export. If you need to keep a see-through background, convert to PNG, or to WebP if you also want a small file.

Can I convert several images at once?

No, there is no batch conversion. Each image is opened, converted and downloaded on its own. For a few files that still goes quickly, since nothing has to be uploaded to a server or downloaded back from one.

Which format should I choose for a website?

Use WebP for photos and graphics whenever your site or platform accepts it, since it is usually the smallest. Use JPEG for photos when you need maximum compatibility, and PNG for logos, icons and screenshots that need crisp edges or transparency.
