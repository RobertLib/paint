How it works

  1. Drop your image — the Image size dialog opens right away.
  2. Type the new width or height; Keep aspect ratio prevents stretching.
  3. Click Apply, then Export and download the resized file.

Pixels, aspect ratio and what size to choose

Width and height are set in pixels, which is what websites, email and social networks care about. With Keep aspect ratio checked, changing one value updates the other, so faces and circles don’t get squashed. As a rough guide, 1920 px on the long side is plenty for a full-screen photo or a presentation slide, 1200 px works for most blog images and email attachments, and 400–800 px is enough for a profile picture or product thumbnail. Making a picture smaller is safe; enlarging it adds pixels but not detail, so it looks softer.

Image size versus Canvas size

Image size… scales the whole picture up or down. Canvas size…, also in the Image menu, changes the area around it instead: the picture keeps its size and the canvas is extended or cut. The 9-point anchor decides where the existing picture sits — choose the center to add an even border on all sides, or a corner to add space in one direction only. That is handy for fitting a portrait photo into a square without cropping it, or for making room for a caption.

Resizing while you export

The Export dialog has its own Scale slider from 10 to 400%. Use it when you want to keep the full-resolution document for further editing but download a smaller copy — 50% for a quick share, for example. The dialog shows the expected file size before you click Download, so you can check whether the image now fits an upload limit. If the limit is about file size rather than pixels, lowering the JPEG or WebP quality helps as well.

Frequently asked questions

How do I resize an image without stretching it?

Leave Keep aspect ratio checked in the Image size dialog and change only the width or only the height. The other value is calculated for you, so the proportions stay exactly as they were. To change the shape as well, crop to the new ratio first, then resize.

Can I make a small image bigger without losing quality?

You can enlarge it up to 8000 × 8000 pixels (less on iPhone and iPad, where Safari caps a canvas at about 16.7 megapixels), but no editor can recreate detail the original never captured, and Paint Studio has no AI upscaling. Small enlargements usually look fine on screen; large ones look noticeably soft.

What is the difference between resizing and compressing?

Resizing changes the number of pixels. Compressing keeps the pixels but stores them more efficiently, usually as JPEG or WebP with a lower quality setting. Reducing dimensions is the most effective way to cut file size, and the two work well together.

Can I resize many images at once?

Not in one go — Paint Studio edits one image at a time and has no batch processing. For a handful of pictures, open each one, set the size and export; since nothing is uploaded, each file takes only a few seconds.
