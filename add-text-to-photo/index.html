How it works

  1. Drop your photo — the Text tool is ready.
  2. Click where the text should go and type; set the font, size and color.
  3. Press Ctrl/⌘+Enter to commit, then Export.

Fonts, size and color

Choose from six fonts: System sans for clean captions, Serif for a classic look, Monospace for code or technical labels, Impact for memes, Handwritten for a personal note and Trebuchet for friendly headings. Size goes from 6 to 400 px, and you can align left, center or right, switch on bold or italic and lower the opacity. The text color is the primary color in the Color panel — set it before typing, or pick it from the photo with the Eyedropper so the text matches the picture.

Editing, moving and layering text

Every piece of text becomes its own text layer in the Layers panel. Click it again with the Text tool to fix a typo or change the wording, and use the Move tool to reposition it. The layer stays editable until something changes its pixels — painting, filters, adjustments including Levels and Curves, the Transform tool, rotating or flipping the image, Merge down, Apply mask, or moving it while a selection is active. After that it is ordinary pixels. To make text readable on a busy photo, add a new layer below it, draw a solid black or white Rectangle and lower that layer’s opacity to create a soft band behind the words.

Memes and watermarks

For the classic meme style, pick Impact, set a large size, center the alignment and use white text near the top and bottom edges. For a watermark, type your name or website in a small size, place it in a corner and set the opacity to around 30–50% so it is visible without covering the picture. Export as JPEG for photos you share, or as PNG if the image consists mostly of text and flat graphics.

Frequently asked questions

Can I edit the text after adding it?

Yes. Each text is a separate text layer; select the Text tool and click the text to change the words, font, size or color. It stays editable until its pixels change: painting, filters and adjustments, the Transform tool, rotating or flipping, Merge down or Apply mask turn it into ordinary pixels. Save a .paint project to keep all layers for later.

Which fonts are available?

System sans, Serif, Monospace, Impact, Handwritten and Trebuchet. You can’t add your own font files, and the exact look of each family may vary slightly between operating systems.

How do I add text to a picture on my phone?

Open this page in your phone’s browser, choose a photo, tap where the text should go and type with the on-screen keyboard. Use the Move tool to drag the text into place, then Export to download the finished image.

Can I rotate text?

Yes, with the Transform tool, which rotates the text layer by any angle. Rotating turns the text into pixels, though, so finish the wording first and rotate it as the very last step.
