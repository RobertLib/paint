How it works

  1. Drop an image or paste a screenshot — the Eyedropper is ready.
  2. Click or drag over the image to sample a color.
  3. Read the HEX and RGB values in the task bar and click Copy HEX.

Getting the exact color

Click anywhere to sample a pixel, or press and drag to watch the value change as you move across the image. The task bar shows the color as a HEX code (such as #1E88E5) and as RGB values, with a Copy HEX button that puts the HEX code on your clipboard; the Color panel shows the color as well. To hit a single pixel — a thin line, a small icon, one letter — zoom in with the scroll wheel or a pinch gesture. At up to 3200% every pixel becomes a large square.

Photos, logos and screenshots

In a photograph, neighboring pixels rarely have exactly the same color, and JPEG compression adds small variations on top. Sample a few points and pick the one that represents the area best. For brand colors, use the cleanest source you have, such as an original PNG or SVG logo rather than a compressed screenshot. To pick a color from a website or app, take a screenshot and paste it with Ctrl/⌘+V. Paint Studio reads the stored RGB values without color management, so results can differ slightly from tools that convert color profiles.

Layers and recent colors

In a document with several layers, choose whether to sample from all layers — the color you actually see — or only from the active layer, which helps when a semi-transparent layer sits on top. Every picked color is added to the Recent row in the Color panel, so you can collect a small palette from one image and reuse it later while painting, drawing shapes or adding text in the same session.

Frequently asked questions

How do I get the HEX code of a color in an image?

Open the image, click the color with the Eyedropper and read the HEX value in the task bar. Click Copy HEX to put it on your clipboard, then paste it into your design tool, CSS file or document.

Can I pick a color from a screenshot?

Yes. Take a screenshot as usual and paste it straight into the page with Ctrl/⌘+V, or save it and drop the file. Zoom in to the exact spot and click it with the Eyedropper.

Why do I get slightly different values in the same area?

Photos contain noise and gradients, and JPEG compression adds small variations, so neighboring pixels often differ by a few units. Zoom in, sample several points and choose a representative one, or use an uncompressed original if you have it.
